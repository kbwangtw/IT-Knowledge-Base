# HPE 5700 核心與 5130 堆疊之間的 LACP：預先設好每台 Port，故障時只要換線

> **一句話**：核心 5700 的 Port 35、36 綁成 Bridge-Aggregation 2；5130 堆疊則把**四台的 Port 52 全部**先加入同一個聚合群組，兩條光纖接任兩台即可，某台壞了只要把光纖移到另一台的 Port 52。

| 項目 | 內容 |
| --- | --- |
| 適合誰看 | 核心交換器往下接堆疊交換器、想要線路與設備都有備援的人 |
| 環境 | HPE 5700（核心）Ten-GigabitEthernet1/0/35～36；HPE 5130 × 4 已組成 IRF，每台 Port 52 |
| 日期 | 2018-07-20（原文發表於 Blogger，2026-10-24 改寫為新手版） |
| 結論 | ✅ 兩條 10G 光纖組成 LACP Trunk，承載所有 VLAN |

## 1. 先認識幾個名詞

| 名詞 | 白話解釋 |
| --- | --- |
| **LACP（鏈路聚合）** | 多條線當一條用，頻寬相加、斷一條還能通 |
| **Bridge-Aggregation** | HPE 的聚合邏輯介面（相當於 Cisco 的 Port-channel） |
| **`port link-type trunk`** | 設為 Trunk，可跑多個 VLAN |
| **`port trunk permit vlan all`** | 允許所有 VLAN 通過 |
| **跨設備聚合** | IRF 堆疊中，不同成員的 Port 可以放進同一個聚合群組 |

## 2. 架構

```text
                    HPE 5700（核心）
           Ten-Gig 1/0/35        Ten-Gig 1/0/36
                 │  Bridge-Aggregation 2  │
     ┌───────────┼────────────┬───────────┼───────────┐
   5130-1      5130-2       5130-3      5130-4       （IRF 堆疊）
   1/0/52      2/0/52       3/0/52      4/0/52
   └─ 四台的 Port 52 都已加入 Bridge-Aggregation 2；光纖只接其中兩台 ─┘
```

**設計重點**：四台的 Port 52 都先設好，故障時不用改設定，**換線就好**。

## 3. 步驟一：5700 建立聚合介面

```text
interface Bridge-Aggregation2
 port link-type trunk
 port trunk permit vlan all
```

> 編號（這裡是 2）自己好辨認就好，兩端不必相同。

## 4. 步驟二：5700 把 Port 35、36 加入群組

```text
interface Ten-GigabitEthernet1/0/35
 port link-type trunk
 port trunk permit vlan all
 port link-aggregation group 2
#
interface Ten-GigabitEthernet1/0/36
 port link-type trunk
 port trunk permit vlan all
 port link-aggregation group 2
```

| 片段 | 意思 |
| --- | --- |
| `port link-aggregation group 2` | 加入 Bridge-Aggregation 2 |
| 實體 Port 也設 trunk | 實體 Port 與聚合介面的 VLAN 設定要一致 |

> 原文在實體 Port 還多了一行 `port bridge enable`（允許同一 Port 進出的流量轉送），一般 LACP 不需要，保留與否請依實際需求（未確認原因）。

## 5. 步驟三：5130 堆疊建立聚合並加入四台的 Port 52

```text
interface Bridge-Aggregation2
 port link-type trunk
 port trunk permit vlan all
#
interface Ten-GigabitEthernet1/0/52
 port link-type trunk
 port trunk permit vlan all
 port link-aggregation group 2
#
interface Ten-GigabitEthernet2/0/52
 port link-type trunk
 port trunk permit vlan all
 port link-aggregation group 2
#
interface Ten-GigabitEthernet3/0/52
 port link-type trunk
 port trunk permit vlan all
 port link-aggregation group 2
#
interface Ten-GigabitEthernet4/0/52
 port link-type trunk
 port trunk permit vlan all
 port link-aggregation group 2
```

## 6. 步驟四：接線與確認

把 5700 的 35、36 兩條光纖，接到任兩台 5130 的 Port 52。

```text
display link-aggregation summary
```

**應該看到什麼**：Bridge-Aggregation 2 有 2 個 Selected Port（實際接線的那兩條）。

**故障演練**：拔掉其中一條，網路仍然通；把光纖改接到另一台 5130 的 Port 52，恢復兩條。

## 7. 常見問題

| 現象 | 怎麼辦 |
| --- | --- |
| Port 顯示 Unselected | 兩端 VLAN、速度設定不一致；或一端沒加入群組 |
| 只想用靜態聚合 | 預設是靜態；要用 LACP 動態協商，在 Bridge-Aggregation 下加 `link-aggregation mode dynamic`（兩端一致） |
| 換線後不通 | 確認新那台的 Port 52 也已加入群組 |

> 原文沒有寫出 `link-aggregation mode dynamic`，表示兩端可能是靜態聚合（推測，未確認）。
